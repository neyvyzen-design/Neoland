# Catatan Perubahan Dynamic Island

## [1.6.9] — 8 November 2026

- 🏠 **Profil Layar Utama dan Layar Kunci dipisahkan sepenuhnya.** Masing-masing menyimpan posisi horizontal, jarak dari atas, lebar, tinggi, dan mode poni kamera sendiri.
- 🔒 **Pergantian profil otomatis.** Saat layar kunci Android tampil, island memakai profil Layar Kunci. Setelah perangkat dibuka, island kembali memakai profil Layar Utama.
- 💾 **Migrasi aman dari versi 1.6.8.** Profil Layar Kunci dibuat satu kali dari pengaturan posisi lama agar tampilan tidak berubah setelah pembaruan. Sesudah migrasi, perubahan pada satu profil tidak memengaruhi profil lainnya.
- 🎚️ **Pengaturan terpisah.** Tab Layar Utama dan Layar Kunci memiliki pengaturan posisi, jarak atas, lebar, tinggi, dan poni kamera masing-masing.
- ♻️ **Atur ulang per profil.** Tombol reset hanya mengembalikan profil yang sedang dipilih.
- 🇮🇩 **Bahasa Indonesia.** Nama workflow, dokumentasi GitHub, catatan rilis, dan keterangan pembaruan menggunakan Bahasa Indonesia.

## Versi sebelumnya

Catatan versi terdahulu dipertahankan dalam riwayat Git repositori. Rilis aktif dan dokumentasi terbaru berfokus pada versi 1.6.9.
